# Identidade ClickImage

`clickimage-logo.svg` preserva o desenho vetorial do `brand-mark` já existente em `panel.html`/`library.html`, com o fundo e cores de `panel.css`. É a fonte reutilizável, com proporções originais e cantos transparentes. Nenhuma marca nova foi criada.

`clickimage-logo-512.png` é uma cópia raster em alta resolução para divulgação. Os PNGs em `icons/` (16, 32, 48 e 128 px) são derivados desse vetor. Apenas os PNGs necessários ficam no pacote da extensão; as páginas internas usam `icons/32.png` como favicon.
