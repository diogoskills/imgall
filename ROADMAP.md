# Roadmap do ClickImage

## Entregue — 2.11

- [x] Leitura de thumbnails com permissões mínimas, fallback verificado e mensagens HTTP/rede.
- [x] Nomes consistentes, blobs com nome registrado e imagens em abas de segundo plano.
- [x] Pasta automática com preferência manual persistida; remoção de PNG Beta.
- [x] Tipos G/C/S sobre a árvore existente, cartões de pastas e escopos direto/árvore nos downloads.
- [x] Fonte reutilizável da marca, ícones e favicons.
- [ ] Homologar permissões CORS e nomes finais com extensão instalada no Chrome do usuário.

## Entregue — 2.10

- [x] Árvore multinível, guias e seleção parcial/total compartilhada.
- [x] Atalhos, menus de contexto e agrupamento seguro por ancestral comum.
- [x] JSON explícito da Biblioteca e manifesto em todos os ZIPs de imagens.
- [x] Limpeza total confirmada, Grade de até três colunas e Donate acessível.

## Entregue — 2.9

- [x] Bibliotecas independentes com migração segura e nomes únicos nas importações.
- [x] Grupos → Conjuntos → Itens, árvore expansível e organização de conjuntos.
- [x] Destino de salvamento lembrado e feedback por cartão.
- [x] ZIP fixo, marcar/desmarcar todas as pastas e seleção pai/filho sem ZIP repetido.
- [x] JSON com arquivos incorporados, ZIP automático para backups maiores e leitura de backups legados.

## Entregue — 2.8

- [x] Coleta temporária preservada e Biblioteca local permanente independente.
- [x] Pastas, pesquisa, seleção múltipla e organização sem duplicar arquivos.
- [x] Originais locais, downloads, ZIPs por pasta e backup/restauração com validação.
- [x] Idiomas, Donate e X sem scripts externos.
- [x] Pacote de publicação reproduzível e regressão automatizada.

## Próximas validações

- [ ] Homologar instalação, atualização sobre 2.8, janelas e downloads no Chrome desktop do usuário.
- [ ] Validar salvamento nos sites reais com suas políticas de CORS e autenticação.
- [ ] Avaliar formatos vetoriais na Biblioteca e exportação incremental de acervos acima de 128 MB, mantendo importações seguras.
- [ ] Preparar revisão e publicação manual na Chrome Web Store; nenhuma publicação automática.

## Planejamento separado

Backend, contas e Mercado Pago dependem de instruções futuras. A Biblioteca desta versão é totalmente local e não depende desse planejamento.
